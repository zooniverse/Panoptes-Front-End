# Feedback Strategy: Geo Line

Determines whether a volunteer's geoDrawing line (the SegmentedLine tool) follows a target line on the map, within a tolerance in meters. The target is given per subject as `#feedback_N_coordinates`, a JSON array of `[longitude, latitude]` pairs.

This feedback is only available in the [Zooniverse Classifier](https://github.com/zooniverse/front-end-monorepo/tree/master/packages/lib-classifier#zooniverse-classifier).
Please see the related [Geo Line documentation](https://github.com/zooniverse/front-end-monorepo/tree/master/packages/lib-classifier/src/store/feedback/strategies/geo/line#feedback-strategy-geo-line) in the Zooniverse Classifier.
