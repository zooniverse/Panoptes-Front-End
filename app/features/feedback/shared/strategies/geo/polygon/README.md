# Feedback Strategy: Geo Polygon

Determines whether a volunteer's geoDrawing point falls inside a target polygon on the map, within a tolerance in meters. The target ring is given per subject as `#feedback_N_coordinates`, a JSON array of `[longitude, latitude]` pairs.

This feedback is only available in the [Zooniverse Classifier](https://github.com/zooniverse/front-end-monorepo/tree/master/packages/lib-classifier#zooniverse-classifier).
Please see the related [Geo Polygon documentation](https://github.com/zooniverse/front-end-monorepo/tree/master/packages/lib-classifier/src/store/feedback/strategies/geo/polygon#feedback-strategy-geo-polygon) in the Zooniverse Classifier.
